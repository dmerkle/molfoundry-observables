# Notebooks

Start with [All examples](paper_examples.ipynb). Use the MolFoundry kernel and
**Restart Kernel and Run All**; each notebook runs independently. Sliders need
a running kernel. Code cells can be folded in JupyterLab.

Adjacent `.py` files contain the same code and are generated by
`scripts/notebook_sources.py`. GitHub shows saved results;
[setup instructions](../README.md) explain how to run them.
